# media/

Put robot photos, wiring shots, the schematic and any demo footage here.

Suggested names:
- `robot.jpg`   — the assembled robot
- `wiring.jpg`  — the real wiring
- `circuit.png` — schematic (draw.io or Fritzing)

For a demo video, upload it to YouTube (unlisted) and link it from the top-level
`README.md` rather than committing an `.mp4`.
